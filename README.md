# HideOwnTweet (Hide Specified Users' Posts on X)

X（旧Twitter）のホームタイムラインから、自分のポストや指定したユーザーのポストを非表示にするブラウザ拡張機能（v2.0）です。通知欄やプロフィール画面ではそのまま表示されます。

## 対応ブラウザ
- **Chrome / Vivaldi / Edge (Manifest V3)**: `chrome/` フォルダ
- **Firefox**: `firefox/` フォルダ

## 主な機能
- 複数の対象ユーザー（`@username`）の追加・削除管理
- ホームタイムライン（おすすめ・フォロー中）でのリアルタイム非表示処理
